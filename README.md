# Презентация: Луна

Интерактивная HTML-презентация о Луне — естественном спутнике Земли.

## Содержание

1. Титульный слайд
2. Что такое Луна
3. Ключевые факты
4. Происхождение Луны
5. Строение Луны
6. Фазы Луны
7. Влияние на Землю
8. Исследование Луны
9. Интересные факты
10. Заключение

## Как открыть

Откройте файл `index.html` в любом современном браузере.

Либо запустите локальный сервер:

```bash
python3 -m http.server 8000
```

и откройте `http://localhost:8000`.

## Навигация

- **← → / пробел / PageUp / PageDown** — переключение слайдов
- **Home / End** — первый / последний слайд
- Кнопки **‹ ›** внизу экрана
- Свайпы влево/вправо на сенсорных экранах

## Файлы

- `index.html` — структура и контент слайдов
- `styles.css` — оформление (космическая тема, анимации)
- `script.js` — навигация, прогресс-бар, звёздное небо

# Сборка .pptx

```bash
pip install python-pptx
python3 build_pptx.py   # создаст luna.pptx
```

Готовый файл: `luna.pptx` (10 слайдов, 16:9).
